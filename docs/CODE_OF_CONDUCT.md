# Code of Conduct

本页是本仓库（含 `stripe_payments.py`、文档与 CI 配置）的行为准则，适用于 Issue、
Pull Request、评论等所有仓库空间。

## 我们期望的行为

- 讨论对事不对人：可以质疑代码和方案，不要攻击提出它的人。
- 尊重不同的经验水平：新手问题同样值得认真回答。
- 提出问题时给出复现步骤和实际看到的输出，方便他人判断。

## 不可接受的行为

- 人身攻击、侮辱、歧视性言论。
- 骚扰、威胁，或未经允许公开他人的隐私信息。
- 在 Issue 或 Pull Request 里粘贴密钥、卡号等敏感信息（安全问题请见
  [SECURITY.md](../SECURITY.md)，不要公开提 Issue）。

## 如何报告

遇到违反本准则的行为，请发邮件至 support@orbi.build，写清相关的 Issue 或
Pull Request 链接、发生的事情，以及你希望的处理方式。

## 处理方式

维护者会通过同一邮箱确认收到、评估情况并给出处理结果；必要时会删除相关内容或
限制继续参与。维护者同样受本准则约束。

## 适用范围

本准则适用于所有仓库空间，以及代表本仓库发言的公开场合。
