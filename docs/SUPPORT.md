# Support

遇到问题需要帮助时，请按下面的渠道求助。

## 提问前

- 先搜一下已有 Issue：同一个问题可能已经有答案。
- 准备好复现信息：你运行的命令（例如 `python -m stripe_payments export`）、
  期望的结果，以及实际看到的输出。

## 求助渠道

本仓库不接受 pull request，问题请通过 Issue 提出（详见
[CONTRIBUTING.md](../CONTRIBUTING.md)）。在仓库的 Issues 页面新建一个 Issue，
写清上面提到的复现信息，维护者会在那里回复你。

## 安全问题的上报

安全问题不要开公开 Issue，也不要把细节写进公开讨论。请按
[SECURITY.md](../SECURITY.md) 的说明，邮件私下上报 support@orbi.build。
